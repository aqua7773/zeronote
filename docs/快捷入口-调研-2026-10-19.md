# ZeroNote · 起始页快捷入口（长按 ＋）· 调研与设计（2026-10-19）

> 状态：**active**（待实现）｜最后核对：2026-10-19 ｜权威范围：起始页长按快捷入口的交互与实现方案
>
> 用户需求原话：「把起始页＋按钮长按做成这样的快捷入口，长按进入一个遮罩，类似手机指纹一指直达的功能（不知道的话就搜索一下），目前先添加一个记账的入口，其他四个空着，只有长按进入，直接点击的话还是创建新笔记」
>
> 附图是手机上的环形快捷菜单（5 个圆形图标环绕中心）——**只借鉴这种环形遮罩的形态**；入口是**笔记内部功能**（第一个 = 记账），不涉及支付、扫码或指纹识别。

## §1 形态参考（只借环形布局，不借指纹 / 支付）

用户要的是**笔记内部的功能入口**，不是支付、扫码或系统快捷。环形遮罩的**视觉形态**参考了手机的「指纹一指直达」（长按 → 弹环形快捷），但：

- **触发**：长按起始页底部的「＋」（新建笔记按钮）——与指纹识别无关，也不调用任何系统快捷；
- **内容**：ZeroNote 自己的功能入口（第一个 = 记账面板；其余 4 个先占位，以后可放搜索 / 回收站 / 设置 / 其它插件面板）；
- **不涉及**：微信 / 支付宝 / 扫码 / 付款码等系统入口。

参考来源只用于描述「长按 → 环形遮罩 → 点一项进入」这种形态：

- [小米 HyperOS 指纹快捷](https://www.huaweicentral.com/have-you-tried-xiaomi-hyperos-3-0-fingerprint-shortcuts/)（长按指纹区 → 快捷入口）
- [Realme Fingerprint Quick Launch](https://www.realme.com/in/support/kw/doc/2071404)（长按指纹 → 自选应用）

ZeroNote 的对应物：起始页圆形「＋」——**短按仍是新建笔记**，长按打开环形遮罩。

## §3 设计

### 3.1 触发

- `pointerdown` 在 ＋ 上开始 500ms 计时；
- 计时到 → 打开遮罩；期间 `pointerup` / `pointerleave` / `pointercancel` 取消（拖动手势不误触）；
- 长按触发后**抑制随后的 click**（否则松手会同时新建笔记）；
- 普通点击（<500ms）→ 仍执行 `onNewNote`（不变）。

### 3.2 遮罩（QuickLaunch）

```
┌────────────────────────────┐
│        （半透明黑 + 模糊）      │
│            ○ 空              │
│      ○ 空      ○ 记账        │
│            × 关闭            │
│      ○ 空      ○ 空          │
│                            │
│       长按进入 · 点空白关闭     │
└────────────────────────────┘
```

- 中心：关闭圆（点击 = 关闭，点空白也关）；
- 环绕 5 个：半径约为容器 1/3，按 72° 均匀分布（从正上方起）；
- 「记账」：实心绿（`--zn-success`）+ 文字；其余 4 个：虚线边框、半透明、`disabled`；
- 记账入口按**面板 title「记账」**查找面板 id（不硬编码插件 id）；插件没装/没加载 → 灰化并标「未安装」。

> 入口内容一律是**笔记内部功能**（面板 / 命令 / 内置动作），不是系统 App 或支付入口。

### 3.3 桌面端

同一组件可直接复用：桌面起始页「新建笔记」按钮也挂长按（鼠标按住 500ms）。**本轮先做手机**，桌面留 v0.2。

## §4 实现清单（下个会话照此开卡）

| 文件 | 改动 |
|---|---|
| `src/components/QuickLaunch.tsx`（新） | 遮罩 + 圆环；props：`open` / `onClose` / `entries`（≤5，`{ key, label, disabled, onClick }`） |
| `src/components/MobileNoteCards.tsx` | ＋ 按钮加长按检测（timer + ref 抑制 click）；新 prop `onQuickLaunch` |
| `src/App.tsx` | `quickOpen` state；传 `onQuickLaunch`；渲染 `<QuickLaunch>`；记账入口 = `panels.find(p => p.title === '记账')` → `setMainView(id)` |
| `src/styles.css` | `.zn-quick-overlay`（fixed + backdrop blur）/ `.zn-quick-ring` / `.zn-quick-center` / `.zn-quick-item`（含 `.is-empty`） |
| `tests/quick-launch.test.tsx`（新） | ① 短按 → 调 `onNewNote`；② 长按 500ms（fake timers）→ 打开遮罩；③ 长按后松手不再触发新建；④ 点「记账」→ `setMainView`（用 props 回调断言） |

**验收（真机）**：
1. 起始页短按 ＋ → 仍是新建笔记；
2. 长按 ＋ 0.5s → 环形遮罩出现（记账绿 + 4 空）；
3. 点「记账」→ 进记账面板；点空白 → 关闭；
4. 指向未安装插件时入口灰化、不报错。

**风险**：
- 与列表滚动冲突：长按开始后若手指移动 >10px 取消（防误触）；
- Android WebView 长按可能触发系统「文本选择」，按钮上需 `user-select: none` + `-webkit-touch-callout: none`；
- 遮罩 z-index 要压过底部状态栏（参考 `.zn-menu-scrim` 的 69）。

## §5 与插件的关系

快捷入口本身是**内核 UI**（起始页是内核的），但入口指向**插件面板**：
- 用面板 title 匹配 → 插件可换名/多面板时由内核列表决定；
- 空位 4 个：先占位，后续可以配置成「插件命令 / 面板 / 内置动作」，不需要改插件 API。
