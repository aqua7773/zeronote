# D-004 插件只住全局目录；store 按库隔离

> 状态：**accepted** ｜日期：2026-10-18（rev173.5）｜重议条件：需要「按库启用/禁用插件」，或 store 跨库共享成为需求

## 背景

插件曾有三种来源（`global` / `vault` / `builtin`，rev94/110）。安卓用户没法方便地把插件放进应用私有目录，且两库各一份插件容易漂移。

## 决定

- 插件代码**只有全局一处**：`<应用数据目录>/.zn/plugins/<id>/`，所有库共用；装卸 = 放/删一个文件夹。
- 插件 `store` 仍在**库根**：`<库根>/.zn/plugins/<id>/store.json`（`private_root(vault)`，子库提升到容器根）。

## 理由

- 安卓上「库内插件」用户摸不到；全局目录才能「装一次，全库可用」。
- store 按库隔离，是为了不同库（工作/个人）有各自的插件数据。

## 代价与边界

**换库 = 换 store，不是「随插件走」**；旧文档里「插件目录内、随插件走」的说法不准确，以此条为准。插件代码与 store 分居两处，排查时要分清。
