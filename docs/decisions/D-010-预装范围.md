# D-010 预装范围：核心体验预装，「增强」类逐步移市场，安全类走市场

> ⚠️ **已被 [D-011](D-011-不预装插件.md) 取代（2026-10-30 · rev173.259）**：应用**不再预装任何插件**，

> 状态：**superseded（被 D-011 取代）** ｜日期：2026-10-26（rev173.179）

## 决定

| 类别 | 规则 | 理由 |
|---|---|---|
| **核心体验** | **预装**（离线可用） | 没有它就不算完整笔记应用；断网 / 首启也得能用 |
| **增强** | **可以逐步移市场** | 用得到才装；不影响「应用是否完整」 |
| **安全 / 密码库** | **市场 + 「官方」标识** | 涉及隐私，用户应当**知情选择**；它不是「没有就不能用」的功能；预装加密插件反而暗示「你的笔记默认不加密」，容易误导 |

### 逐插件归类（2026-10-26 落定）

| 类别 | 插件 | 处置 |
|---|---|---|
| 核心体验 | `tag-panel`（标签）· `backlinks`（反链）· `history`（历史版本）· `import-export`（导入导出） | 预装 |
| 核心体验 | `sync-folder` / `sync-webdav` / `sync-s3` / `sync-git` | 预装 |
| 核心体验 | **`backup`（备份）** —— 2026-10-26 补入 | 预装：不碰隐私、不暗示风险，是「数据会丢」这个系统缺口的地基 |
| 增强 | `outline-map`（大纲导图）· `doc-reader`（文档阅读器）· `accounting`（记账）· `theme-sepia`（米色主题）· `habit`（打卡） | **移市场**（rev173.179 执行） |
| 安全 | `security` · `secrets` | 已在市场（rev173.161 / rev173.163） |

> `habit`（打卡）与 `accounting`（记账）同类 —— 都是**业务功能**，不是系统能力。归「增强」。

## 本次执行（rev173.179）

- `src/kernel/builtin-plugins.ts` 移出 5 个：`outline-map` / `doc-reader` / `accounting` / `theme-sepia` / `habit`
- 预装数 **14 → 9**
- 五个插件的源码仍在 `examples/`，市场包都在（`outline-map@0.2.0` / `doc-reader@0.1.0` / `accounting@0.1.0` / `theme-sepia@0.1.0` / `habit@0.1.0`）
- **已装环境不受影响**：`ensureBuiltinPlugins` 只是不再写内置版；已经写在全局插件根里的目录不会被动

## 以后加新插件怎么判

1. 先问「没有它，应用还完整吗？」—— 不完整 ⇒ 核心体验，可预装
2. 它是「某个用途」（记账 / 打卡 / 阅读器 / 导图）⇒ 增强，走市场
3. 它涉及隐私 / 加密 / 凭据 ⇒ 安全类，走市场 + 官方标识
4. 判不准 ⇒ 先走市场（可以后补预装，反过来很难：用户已经装过的东西不能悄悄改成内置版）
