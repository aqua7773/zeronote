## 桌面

- **dev 怎么起**：双击 `dev.cmd`（vite 1420 · CDP 9222 · 日志 `.self-logs/desktop-dev.log`）。**别用后台 job 托管**（随会话回收）；AI 里用 `Start-Process cmd.exe /c dev.cmd -WindowStyle Minimized`；**别用管理员**（污染 WebView2 UDF ⇒ `0x800700AA`）。
- **HMR 断了、F5 也救不回**：vite 日志有 `hmr update` 但界面纹丝不动 ⇒ 直接重启 dev，别去查代码（判据：客户端 HMR WebSocket 断、页面重载也没接上）。
- **dev 崩溃**：连续多次 HMR 会 `0xc0000374`，重启即恢复。**别用 `plugin:window|destroy` 关窗口**。
- **改 `tauri.conf.json` / `Cargo.toml`** ⇒ tauri CLI 自动重编重启（与 `cargo test` 争 target 目录，verify 慢是排队不是卡死）。
- **改 `patches/@atomic-editor__editor@…patch` 后必须重启 dev**：结束进程树 → 删 `node_modules/.vite` → 重起（预构建缓存在内存里）。
- **Low IL 会让 dev 起不来**：`icacls src-tauri /setintegritylevel (OI)(CI)Medium`（target 同步）。判据 = `create_dir_all` 报「拒绝访问 (os error 5)」。
- **编辑器 CSS 在 `MarkdownEditor.tsx` 的 JS 模板字符串里** —— 注释里写反引号会提前终止 ⇒ 整页白屏。
- **`PrintWindow` 可能返回缓存帧**：连续截图 sha256 相同 ≠ 功能没坏。改用 `Graphics.CopyFromScreen` 抓实时内容。

## 手机 / adb

- **装的是哪种包决定一切**：只有 `pnpm tauri android dev --config tauri.android-dev.json` 装出来的包才连 `192.168.1.3:1420`；`build` 出的 `app-*-debug.apk` 是**离线包**（内置 dist），点不动也连不上 dev。判据：`dumpsys package` 能看 versionName，但"连不连 dev"只能看点击有没有响应 / 页面是否热更新。
- **连通性别用 ping**：Windows 拦 ICMP 会误判成不通。用 `adb shell "toybox nc -w 3 192.168.1.3 1420 </dev/null && echo OK"`。
- **`adb reverse tcp:1420` 对 dev 包无效**：tauri CLI 把 devUrl 的 `localhost` 换成局域网 IP，手机走 WiFi 直连宿主机；reverse 只对 `localhost` 有效。
- **点小按钮用 swipe 不用 tap**：`input tap` 在 WebView 里点卡片 ⋯ 这类小目标常常不生效；`input swipe x y x y 700`（同坐标按住 700ms）可靠。
- **截图**：`adb shell screencap -p /sdcard/x.png` + `adb pull`；**CDP `shot` 抓不到 WebView 里的 canvas**。
- **设备分工**：测试机 `33b676f6`（Redmi 24069RA21C）只跑 `com.aqua.zeronote.debug`；正式机 `324652868237`（努比亚）只做 release 验收，不调试 / 不 push / 不改系统设置。
- **Android dev 构建**：`android-dev.cmd`（WMI 起，日志 `.self-logs/android-dev.log`）。三条硬前置：① 4 个 android target 已装 ② vite 必须让局域网可达（`host` 不能只听 localhost）③ 库不能放 PC 路径。

## 构建 / 工具链

- **Rust 产物必须在工作区外**：`CARGO_TARGET_DIR=%USERPROFILE%\cargo-targets\zeronote`（工作区内编 C 依赖报 MSVC D8050）。
- **crates.io 直连约 34 KB/s** ⇒ 项目级 `.cargo\config.toml` 走 rsproxy。
- **gradle wrapper 走腾讯镜像**：`services.gradle.org` 在本机 5 分钟 0 字节卡死，已改成 `mirrors.cloud.tencent.com`。
- **rustup 操作必须串行**：与 `tauri android init` 并发会报 `detected conflict`。
- **`.gitattributes` 的 `* text=auto` 会损坏二进制**：`*.jar` 必须显式 `binary`，否则入库即坏。
- **`check-docs` 的硬门**：HANDOFF 最新 rev 段必须带「证据」「未做」两行；HANDOFF 索引里的 rev 必须在正文有 `> ## 📌 rev…` 段；交接卡 ≤120 行。

## 怎么加一条

1. **标题写症状**（下次搜索能命中），正文写「判据 → 处置」；只写可复现、已验证的，不确定标【推测】。
2. 与 `HANDOFF.md` 的 rev 段分工：rev 段写「这次发生了什么」，这里写「以后怎么避免」。
3. 加完跑 `node scripts/check-docs.mjs`（新文档要在 `docs/README.md` 权威矩阵登记，否则红）。
