## 0. 核心决策摘要

- **产品定位**：个人使用、本地优先、隐私强、纯 Markdown、简洁即时渲染的笔记应用。

- **核心场景**：灵感速记、文章写作、日常记录。

- **参考体验**：Effie 的简洁即时渲染 + flomo 的聊天式记录。

- **平台**：Windows + Android 优先，一套代码跨平台；后续扩展 Linux / macOS / iOS。

- **技术栈**：Flutter + SQLite + Markdown 文件 + 插件化同步。

- **数据原则**：Markdown 是唯一真源；SQLite 只做索引、搜索、同步状态。

- **同步原则**：用户自配云端；应用不负担云端存储费用；云端可只做传输，不长期存原文件。

- **开发方式**：用 AI 编程 Agent 写代码，笔记应用内不强制集成 AI 对话。

- **商业模式**：先个人使用，买断授权接口后置。

- **实施策略**：架构全量设计，功能分三期实现。

## 1. 目录与数据模型

### 1.1 目录结构

text

笔记库/
  笔记/
    2026/
      10/
        05/
          14-08-01.md
          14-08-32.md
  文章/
    文件夹1/
      文章1-1.md
      子文件夹/
        文章.md
    文件夹2/
  自定义文件夹/
    文件夹1/
  .assets/
    origin/
    preview/
  .app/
    index.sqlite
    sync/
    conflicts/

规则：

- `笔记/年/月/日/HH-mm-ss.md` 结构用户不可修改。

- 灵感流中每条消息保存为一个 `.md` 文件。

- 同一天自动创建当天文件夹，不生成每日汇总文件。

- `文章/`、`自定义文件夹/` 用户可自行新建、修改、删除。

- 附件原文件存 `.assets/origin/`，预览存 `.assets/preview/`。

- 笔记库默认放应用私有目录；外部编辑器想打开时，先导出 `.md`。

### 1.2 Markdown 文件格式

正文为纯 Markdown。元数据放 frontmatter：

markdown

---

id: 01J...
created: 2026-10-05 14:08:01
updated: 2026-10-05 14:10:22
tags: [灵感, 写作]
level: 公开
attachments:

- id: asset_001
  type: image
  preview: .assets/preview/asset_001.webp

---

今天想到一个笔记应用的点子……

附件引用使用资产 ID：

markdown

![图片](asset://asset_001)

导出时再替换为实际路径。

### 1.3 文件命名

- 灵感短笔记：`HH-mm-ss.md`

- 长文：`时间戳-标题.md`

- 冲突副本：`原文件名.conflict-平台-时间.md`

### 1.4 SQLite 表

- `notes`：文件路径、ID、标题、创建时间、更新时间、密级、标签。

- `tags`：标签名、聚合关系。

- `note_tags`：笔记与标签关联。

- `attachments`：附件 ID、类型、原文件路径、预览路径、大小、同步状态。

- `sync_state`：同步状态、版本、最后同步时间。

- `conflicts`：冲突副本记录。

- `settings`：同步配置、密级策略、导出设置。

## 2. 核心功能

### 2.1 灵感流

- 聊天式输入框。

- 每条发送保存为一条 `.md`，存入 `笔记/年/月/日/HH-mm-ss.md`。

- 按时间流展示 `笔记/` 文件夹内容。

- 点击某条进入编辑器编辑该 `.md`。

- 支持快捷标签。

- 电脑端支持组合键：一键代码块、一键标题等。

- 手机端提供辅助输入工具栏。

### 2.2 编辑器

- 类似 Effie 的即时渲染。

- 支持 Markdown 全格式：标题、列表、待办、表格、代码块、公式、引用、图片、音频、视频等。

- 字数统计。

- 支持 `[[文件名]]` 笔记引用与跳转。

- 反向链接后置。

- 在“笔记”目录下，只能在当天时间目录新建笔记。

- 灵感流与编辑器通过快捷按钮切换。

### 2.3 文件夹与标签

- 多层级文件夹。

- “笔记”目录结构固定；其他目录可增删改。

- 标签聚合查看。

- 相似标签聚合。

- 搜索范围：正文、标题、标签。

- 第一版普通全文搜索；语义搜索后置。

### 2.4 附件与大文件

- 阈值：≤ 1MB 为小文件，> 1MB 为大文件，阈值可配置。

- 小文件：自动同步到本地。

- 大文件：云端只存预览。

- 预览规则：
  
  - 图片：压缩预览图。
  
  - 视频：首帧。
  
  - 音频：波形图。
  
  - PDF：首页。
  
  - 其他：文件类型图标 + 文件名。

- 大文件点击后提示：“此文件体积较大，是否进行同步？”

- 同步方式：端 → 云 → 端，临时中转，完成后云端清除原文件。

- 源设备离线时，检索其他设备是否有本地存储；没有则无法同步。

- 预览始终保留，原文件不长期存云端。

### 2.5 同步

- 实时自动同步。

- MVP 支持：
  
  - WebDAV
  
  - 本地文件夹同步，用户可配 Syncthing / OneDrive / 网盘等。

- 扫码配置后置。

- 冲突处理：
  
  - 正常情况以最新为准。
  
  - 检测到双端离线修改时，生成冲突副本，不弹窗阻塞。
  
  - 副本按平台分文件夹存放。

- 同步状态页：显示进度、大文件传输提示、错误信息。

### 2.6 密级与加密

| 密级  | 云同步     | 加密    | AI 标签    | 搜索索引 |
| --- | ------- | ----- | -------- | ---- |
| 公开  | 可明文     | 否     | 可用       | 可云索引 |
| 秘密  | 可云      | 传输加密  | 可用，需用户确认 | 本地索引 |
| 机密  | 可云      | 端到端加密 | 禁用       | 本地索引 |
| 绝密  | 仅本地/局域网 | 二级验证  | 禁用       | 仅本地  |

- 绝密局域网传输后置。

- 每篇笔记 frontmatter 中标记密级。

- 密钥管理：主密码 + 设备密钥 + 恢复码。

### 2.7 AI 自动标签

- 第一版：大模型 API 自动打标签 + 普通全文搜索。

- 示例：搜索“食物”可命中包含鸡蛋、青菜、牛奶的笔记。

- 语义搜索后置。

- 机密、绝密禁用大模型 API。

### 2.8 导出

支持导出：

- PDF

- HTML

- Word

- 图片

- 纯文本

- Markdown

附件保留链接；需要时打包附件。

5. **设置页**：同步配置、密级、加密、导出、主题。

6. **同步状态页**：同步进度、大文件传输提示。

## 5. 验收用例

### 场景一：手机记灵感，电脑查看

1. 手机灵感流输入一条短笔记。

2. 自动保存为 `笔记/年/月/日/HH-mm-ss.md`。

3. 实时同步到云端。

4. 电脑打开软件，看到相同内容。

5. 电脑修改，手机打开后看到修改。

### 场景二：大图片按需同步

1. 手机写一条笔记，包含 6MB 图片。

2. 手机浏览时显示预览图，点击可打开本地源文件。

3. 云端只同步预览文件。

4. 电脑打开笔记，看到预览图。

5. 点击预览，提示“此文件体积较大，是否进行本地同步？”

6. 确认后，原文件从手机临时中转至电脑。

7. 同步完成后，云端清除原文件。

8. 电脑再次点击，打开本地文件。

## 6. 非目标与后置项

- 多人协作、评论、权限。

- 应用内 AI 对话助手。

- 云端长期存储大文件。

- 不负担云端存储费用。

- 外部编辑器直接打开私有目录，先导出。

- 大文件跨平台保持原链接有效，改为预览 + 按需同步。
