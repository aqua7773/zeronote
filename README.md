# ZeroNote —— 空内核的本地 Markdown 笔记应用

> 一句话：**内核只做四件事**（`.md` 读写 / 编辑 / 本地存储 / 插件宿主），其余功能全是插件，可独立装卸升级。
> **数据就是你文件夹里的 `.md`** —— 没有数据库、没有服务器、没有账号。

**开源 · MIT（2026-10-25）** · **请先读免责**：插件与内核**同权限运行** —— 一个插件能看到你的所有笔记、
能往任意路径写文件、能发网络请求。内核**不提供沙箱**（见 `docs/架构原则-2026-10-13.md`），
所以「装谁的插件」就是全部的安全边界：优先用带签名（`signature.json`）且你信任其作者的。
本软件按「原样」提供、不担保任何用途；你的笔记请自行备份（同步 / Git / 直接拷文件夹都行）。

**现状（2026-10-30 · 0.8.0 + UI 重布局 B1–B7 全量落地）**：桌面（Windows）＋ Android 双端跑通；**AI 管家**（`ai` 插件走市场：对话 / 只读工具 ×5 / 写工具 ×7 / 任务系统 / 命令白名单 —— 「完成」由宿主核对，没对应工具成功就红字标出；当前 **0.9.0**）；**附件与同步**（1 MiB 分流 · 图片两模式 · 引用台账 · 跨设备手动搬运 · 库外附件文件卡片 · Android 大视频 Range 服务）；**安卓桌面组件三件**（快速记录 / 今日打卡 / 最近笔记）；**安全 / 密码库**（两个插件走市场装：`security` 双密钥环 · XChaCha20-Poly1305 + Argon2id，`secrets` 整库加密的密码库 —— 生成器 / 复制后 60 秒清剪贴板 / 空闲 60 秒自锁；桌面 **Windows Hello** 与 Android **指纹**解锁，锁定后自动弹，绑定**按设备**、换机只失效那一台）；**私密文件夹**（三期已落地：`.zn/private/` 整棵树加密、每篇一密文 + 加密索引、文件名是随机 id，独立入口与主密码，编辑器照常用（靠内核 `doc.registerCodec`）；独立搜索 / 回收站 / 公开⇄私密移入移出、四后端同步私密树、备份含私密树 —— rev173.180–182）；**插件市场**（**插件中心 → 插件市场 tab**：列表 / **详情页（含能力自述）** / 一键装、升 / **可更新角标** / **启动 24 小时节流检查**，整包 sha256 对不上就不落盘，**不自动升级**）；插件系统 v0.2（12 原语 / 21 种 UINode / 真窗口 / 整窗接管 / 懒激活）；**桌面壳（B1，rev173.256）**：48px 图标栏（笔记 / 搜索 / 时间流 / 插件 / 设置）+ 侧栏视图容器（文件树 / 搜索 / 时间流）+ 标题栏常驻 + ☰ 主菜单，零插件下全部成立；**手机壳（B2，rev173.257）**：底部四项（首页 / 搜索 / 插件 / 更多）+ 搜索/更多全屏页 + 编辑态返回；**插件中心（B3，rev173.258）**：已安装 / 插件市场 / 调试独立成页，设置瘦身成「摘要 + 入口」（不再有插件列表），禁用可撤销；**B4–B7（rev173.260–267）**：文档工具条（反链 / 历史迁入）+ 状态栏瘦身 · 标签条 `＋`/`»` · 插件面板 `sidebar` 真载体 · 动效 token 统一 + 页面转场 + 侧栏收起 220ms；

## 下载安装（不编译）

在 [Releases](https://github.com/aqua7773/zeronote/releases/latest) 下对应平台的安装包：

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `ZeroNote_<版本>_x64-setup.exe` | NSIS 安装包，装完建快捷方式（推荐） |
| Windows | `ZeroNote_<版本>_x64_zh-CN.msi` | MSI（简体中文语言包），适合批量 / 组策略分发 |
| Android | `ZeroNote_<版本>_arm64-v8a.apk` | **绝大多数手机下这个**（近十年的安卓机都是 arm64），允许「安装未知来源应用」 |
| Android | `ZeroNote_<版本>_armeabi-v7a.apk` | 老的 32 位安卓机（2016 年前后及更早），包更小 |
| Android | `ZeroNote_<版本>_x86.apk` / `_x86_64.apk` | 只在电脑上跑安卓模拟器时用 |

> 0.8.0 起才有安装包附件，更早的 tag 只有更新日志。安卓包按 CPU 架构分开打包（不提供 118 MB 的 universal 包）。

## 怎么跑（桌面，约 10 分钟；首次编译 Rust 多等 10–20 分钟）

```powershell
$env:Path = "$env:USERPROFILE\.cargo\bin;" + $env:Path
# 本机铁律：Rust 编译产物必须在工作区之外，否则 cl.exe 报 D8050
$env:CARGO_TARGET_DIR = 'C:\Users\AQUA\cargo-targets\zeronote'
cd C:\Users\AQUA\Documents\deepseek\ZeroNote
pnpm install
pnpm tauri dev        # 或双击 dev.cmd（带 CDP 调试端口 + 看门狗关闭）
```

只跑前端（不启动桌面壳，`invoke` 会失败，仅用于看样式）：

```powershell
pnpm dev          # http://localhost:1420
```

## Android（真机）

```powershell
# 一次性前置（换机才需要）
rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
pnpm tauri android init --ci

# 日常启动（WMI 起进程 + 日志落 .self-logs\android-dev.log）
android-dev.cmd
```

三条已经固化在配置里的硬前置（踩过的坑）：

1. **`vite.config.ts` 的 `server.host: true`** —— 真机经局域网 IP 访问 dev server
2. **`gradle-wrapper.properties` 指向腾讯镜像** —— 官方源在本机实测 5 分钟 0 字节
3. **Android 默认库 = 公共存储 `Documents/ZeroNote`**（`/storage/emulated/0/Documents/ZeroNote`）；必须手动开「所有文件访问」（系统不弹窗）

安装与权限步骤见 `docs/guides/Android安装说明.md`。

## 自检（提交前必过三条基线）

```powershell
pnpm exec tsc -b                 # 0 错误
pnpm exec oxlint src             # 0 error（warning 数只许减不增；全仓扫会把 examples 也算进去）
cd src-tauri; cargo test --lib   # 必须全过
# 或一键：pwsh -File scripts\verify.ps1（打印真实数字，文档不写死）
```

CI 用同一套门（`.github/workflows/verify.yml`，windows-latest）：本地绿但 CI 红，通常是测试依赖了本机
环境（locale / 路径 / 时区）—— 改代码让结果确定，别改 CI 去迁就。

```

    kernel\            原语实现 + 插件宿主 / 插件来源（`plugin-roots.ts`）/ 内置插件（`builtin-plugins.ts`）

  scripts\             一键自检 / 插件打包签名 / 市场索引 / 内核快照

```

## 参与 / 贡献

- **改代码、写插件、提 PR**：先读 **`CONTRIBUTING.md`**（环境 / 提交前门禁 / 代码与插件约定 / PR 流程）。
- **把自己的插件加进市场**：按 **`market/README.md`** 的两步投稿走 —— 源码留在你自己的仓库，
  这里只加一行 `market/external.json`；发新版不用再来改这个仓库。
- **报 bug / 提建议**：`.github/ISSUE_TEMPLATE/` 里有表单（**数据异常请注明，会优先处理**）。

> 插件与内核同权限运行、没有沙箱：装之前看源码，投稿时也要让人能看。

## 铁律

1. 内核代码**不实现**「标签 / 同步 / AI / 画布 / 灵感流」这些功能（内置插件只是把插件打包分发，逻辑仍在插件里）
2. 只有 `.md` + frontmatter，**没有私有笔记格式**
3. 所有写入原子；删除进 `.zn/trash/`；只接受库内相对路径
4. 改契约 → 必须同步改 `docs/内核契约-v0.2.md` 并升版本
