## 0 一句话方案

**把「隐藏菜单」换回「常驻导航」，但只把「内核保证成立」的东西写进导航**：桌面加 48px **左侧图标栏**（笔记 / 搜索 / 时间流 / 插件 / 设置，五项全内核），插件功能由「插件固定区」按需 pin；侧栏变**可切换视图容器**；手机加**底部四项**（首页 / 搜索 / 插件 / 更多，同样全内核）；「插件 / 市场 / 调试」从设置拆成**插件中心**；状态栏回归纯状态；☰ 从侧栏开关改回**主菜单**。

一句话验收：**在「全部插件禁用」与「全部启用」两种状态下，新用户都能在 3 秒内指出「搜索、插件、设置」在哪，且没有任何死按钮。**

## 1 目标与非目标

### 1.1 目标（按优先级）

| # | 目标 | 对应问题 |
|---|---|---|
| G1 | 所有一级功能有**常驻、可见、有文字/图标**的入口 | D1、D2、D6 |
| G2 | 侧栏承载「同一类东西」：文件树、搜索、时间流各自一个视图，不再是一个大杂烩 | D2、D7 |
| G3 | 「设置」只放偏好；插件安装/市场/调试独立成页 | D3、D5 |
| G4 | 状态栏只放状态；与当前文档相关的工具（反链 / 历史）贴着文档放 | D4 |
| G5 | 手机端底部常驻四项，长按手势只做加速 | D6 |
| G6 | 空态补「最近 3 篇」回访入口（三态与主行动已具备；「标签 / 导入」仅在插件启用时出现） | D8、D11 |
| G7 | 插件契约不破坏：`location` 六类语义与现有插件不改代码即可跑 | §7 |
| G8 | **零插件基线**：全部插件禁用时，壳与一级入口全部成立，不出现空壳 / 死按钮 | D11 |

### 1.2 非目标（明确不做）

- 不做分屏 / 网格布局（`UI交互规范.md` §9 已记）。
- 不做可拖拽自定义图标栏（v1 固定 5 项内核 + 最多 3 个插件 pin；排序 v2 再做）。
- 不引入账号 / 云收件箱 / 协作（ZeroNote 无服务端）。
- 不重写编辑器 / 插件面板内部 UI（本次只改**壳**与**入口**）。
- 不改 `location` 字段名与 manifest 格式（只补语义与校验）。
- 手机不做第 5 个底部 tab，不做「More」溢出菜单式的伪 tab。
- 不把插件功能「收编进内核」来凑导航项（例如为了固定「标签」图标而重写 tag-panel）。

### 1.3 零插件基线（硬约束）

> 事实依据：禁用插件不注册面板 / 命令（`usePluginHost.ts:313`）；内置 9 个是「预装」不是「强制」（`builtin-plugins.ts:93-125`）。完整现状见调研 §1.8。

**规则：图标栏 / 底部导航 / 侧栏视图 / 空态只写内核能力；插件能力一律「按需出现」，禁用即整块消失，不留灰按钮、不留空壳。**

| 能力 | 来源 | 零插件下 | 入口归属 |
|---|---|---|---|
| 文件树 / 回收站 / 切库 | 内核 | ✅ | 侧栏 / 图标 1 |
| 编辑 / 保存 / 多标签 / 拆窗 | 内核 | ✅ | 主区 |
| 搜索（含标签 / 目录 / 正则筛选） | 内核（`index-api.ts` 自己解析 frontmatter 标签） | ✅ | 图标 2 / 侧栏搜索框 |
| 时间流 | 内核（`MobileNoteCards`） | ✅ | 图标 3 |
| 命令面板 / 快速切换 / 全局替换 | 内核 | ✅ | `Ctrl+P/O/Shift+H` |
| 插件中心（安装 `.znp` / 市场 / 调试） | 内核壳 + 内核 `market.ts` | ✅（空列表 + 安装入口 + 市场） | 图标 4 / 手机底部 |
| 设置（通用 / 附件 / 关于） | 内核 | ✅ | 图标 5 |
| 智能分区：今天 / 最近 / 未打标签 | 内核索引（`mtime` + `tagsOf()`） | ✅ | 文件树视图顶部 |
| 插件类：标签 / 反链 / 历史 / 同步 chip / 导入导出 / 安全 / 密码库 / 记账 / AI… | 插件 | ❌ | 插件固定区 · 文档工具条 · 状态栏 chip · 插件中心 |

**「插件固定区」**：图标栏下半部分（分隔线以下），由用户把「插件面板 / 插件命令」pin 进来，最多 3 个；默认空。零插件时这一区不渲染任何占位。手机端对应「更多 → 插件」页里的「已固定」列表。

## 2 目标信息架构

### 2.1 桌面（≥ 1024px）

```
┌ 标题栏 36px ────────────────────────────────────────────────────────┐
│ ☰ 菜单 │ 库名 / 文档面包屑 │ 保存状态            ─  □  ×          │
├ 图标栏 48 ┬ 侧栏 260 ┬ 主区 ───────────────────────────────────────┤
│ 📄 笔记   │ 搜索框    │ 标签条  ＋  »                                │
│ 🔍 搜索   │ 智能分区  │                                              │
│ 🕒 时间流 │ 文件树    │ 编辑器 / 文档 / 工具页                       │
│ ──────    │  ─────    │                                              │
│ 🧩 插件   │ 回收站    │                                              │
│ ⚙ 设置    │ 库名      │                                              │
│ (pin 区)  │           │                                              │
├──────────┴───────────┴──────────────────────────────────────────────┤
│ 状态栏 24px：已保存 · 本地库 · [同步：2 分钟前] · 42 字                │
└──────────────────────────────────────────────────────────────────────┘
```

**图标栏（Activity Rail）—— 上半区固定 5 项（全部内核能力）**

| # | 图标 | 名称 | 点击行为 | 再点 | 零插件下 |
|---|---|---|---|---|---|
| 1 | 📄 | 笔记 | 侧栏切到「文件树」视图 | 收起侧栏 | ✅ |
| 2 | 🔍 | 搜索 | 侧栏切到「搜索」视图并聚焦输入框 | 收起侧栏 | ✅ |
| 3 | 🕒 | 时间流 | 侧栏切到「时间流」视图 | 收起侧栏 | ✅ |
| 4 | 🧩 | 插件 | 主区打开**插件中心**页 | 回到之前的文档 | ✅（空列表 + 安装 + 市场） |
| 5 | ⚙ | 设置 | 打开设置 | 关闭 | ✅ |

**图标栏下半区（分隔线以下）：插件固定区**

- 用户从插件中心把「面板 / 命令」pin 到这里，最多 3 个；默认空；**零插件 / 插件被禁用 ⇒ 整块不渲染**（不留虚位、不留灰图标）；标签、记账、AI 都在这里，不在上半区。
- 图标栏**不随侧栏收起**（Obsidian Ribbon 规则）；选中态 = 图标 + 2px 左侧竖条 + 深色底（`aria-current="page"`）；**设置固定在底部**（NavigationView 惯例），每个按钮的 tooltip 带快捷键（如「笔记 Ctrl+1」）。

**侧栏（视图容器，3 个内核视图）**

- 顶部固定：搜索框（输入即切到搜索视图）+ 收起按钮（`«`）；中部 = 文件树 / 搜索结果 / 时间流；底部 = 回收站 · 库名（切库）。
- 视图切换不改侧栏宽度（记忆 `zeronote.sidebar.w`，默认 260，范围 220–420）。
- 「智能分区」只在文件树视图顶部出现：**今天 / 最近 7 天 / 未打标签**（内核索引：`mtime` + `index-api.ts:101` 的 `tagsOf()`；不做「收藏」，内核没有收藏功能）。

**主区**：标签条（笔记 + 工具页 + 右侧 `＋` 新建 / 选面板 + `»` 溢出列表）→ 内容（文档页 / 工具页 / 系统页，见 §3）。文档工具条固定「源码 / 更多」；**反链 / 历史只在对应插件启用时追加**，禁用即消失（不占位）。

**状态栏**：左 = 保存状态 + 库类型 + **同步 chip（仅同步插件启用时）**；右 = 字数 / 光标位置。**不再承载**篇数统计、反链 / 历史 / 安全、插件入口。

**标题栏**：`☰` = **主菜单**（新建 / 打开库 / 打开文件 / 导入 / 导出 / 最近打开 / 窗口 / 关于 / 退出）；中间 = 面包屑；右侧 = 保存状态 + 三键。**默认常驻**（自动隐藏只在「专注模式」下启用；保留则必须给「始终显示标题栏」设置项，默认开）。

### 2.2 手机（< 641px）

```
┌ 顶栏 48px ─────────────────────────────┐
│ 〈 返回 │ 笔记名 / 页面名 │ ⋯ 更多    │
├ 内容 ─────────────────────────────────┤
│ 首页：卡片流（顶部搜索框 + 今天/最近）  │
│ 搜索：全屏搜索结果                     │
│ 插件：插件中心（已安装 / 市场 / 调试）  │
│ 更多：设置 / 回收站 / 库 / 标签 / 导入  │
├ 底部导航 56px ─────────────────────────┤
│  🏠 首页   🔍 搜索   🧩 插件   ⋯ 更多   │
└────────────────────────────────────────┘
＋（首页悬浮）：短按新建；长按 500ms 环形快捷入口（保留）
```

- 底部四项**固定 ID 与顺序**：`home / search / plugins / more`（验收点；全部内核级，零插件下照常成立）；**贴底留 `env(safe-area-inset-bottom)`**，只放点击目标不放拖拽（避 Android 手势区），**编辑态隐藏底部导航**（键盘上方工具栏接管）。
- 「插件」格零插件下不是死按钮：打开插件中心空态 = 安装 `.znp` + 浏览市场 + 3 条推荐（标签 / 反链 / 历史）。
- 「更多」= 全屏页（不是抽屉）：设置 / 回收站 / 切换库 / **标签（`tag-panel` 启用才出现）** / 导入导出（启用才出现）/ 关于 / 帮助。点未启用的插件入口 ⇒ 「需要启用 X 插件」+ 一键去插件中心，而不是空页。
- 首页顶部「今天 / 最近 / 未打标签」是内核智能分区，不依赖 `tag-panel`。
- 进笔记 = push 一层；返回 = 回该 tab 根视图；切 tab 不叠加返回栈（M6）。编辑态顶栏 `〈 返回 | 笔记名 | ⋯`，`⋯` = 重命名 / 移动 / 属性 / 查找替换 / 历史 / 分享 / 删除。
- 键盘上方工具栏保留（`⇤ ⇥ 📎 🔍 B …`），只补「格式」分组；长按 ☰ / 长按卡片 / 左滑抽屉保留为加速手势，但**每项都有可见替代**。

### 2.3 平板 / 窄桌面（641–1008px）

- 图标栏收窄到 44px，侧栏默认收起（点图标弹 overlay 侧栏）；主区占满，时间流默认关闭。

### 2.4 动效（摘要；完整规格见 [`UI动效与页面转场-2026-10-30.md`](../_research/UI动效与页面转场-2026-10-30.md)）

| 场景 | 时长 | 缓动 |
|---|---|---|
| 高频：标签切换 / 标题栏显隐 | 0–80 / 200ms | linear / standard |
| 同级：图标栏视图 / 底部 tab / 「更多」 | 160ms | standard |
| 浮层：设置 / 命令面板 / 菜单 / 环形入口 | 120–140ms | emphasized-decelerate |
| 钻入：列表 → 编辑器（返回反向） | 260ms | emphasized |
| 侧栏 / 抽屉 | 220ms | emphasized |
| 拖拽中（侧栏宽度 / 抽屉跟手） | 0 | — |

- 只动 `transform` / `opacity`；`prefers-reduced-motion` 下全部 ≤80ms，钻入改直接切换；任一时刻只允许一层做大动作。

## 3 页面与窗口归属（目标）

### 3.1 主区页面三类

| 类型 | 例子 | 来源 | 进标签条？ | 退出方式 | 零插件下 |
|---|---|---|---|---|---|
| **文档页** | 笔记 | 内核 | 是（每篇一签） | 关标签 | ✅ |
| **文档页（阅读器）** | PDF / EPUB / MOBI / FB2 / CBZ | 插件 `doc-reader` | 是（每篇一签） | 关标签 | ❌ 菜单/命令消失 |
| **工具页** | 标签、记账、AI、备份、同步、打卡、密码库、灵感流 | 插件 | 是（一页一签，标题前加插件图标） | 关标签 | ❌ 全部消失 |
| **系统页** | 回收站、插件中心、设置 | 内核 | 否（不进标签条） | 图标栏再点 / 返回 / Esc | ✅ |

- 规则：**用户内容的页进标签；系统管理的页不进标签**（VS Code：编辑器进 tab，Settings 不进）；工具页必须能从「插件中心 / 插件固定区 / 命令面板」直接打开，不依赖 ☰ 菜单。
- 零插件时工具页一个都不存在；主区只剩「空态 / 编辑器 / 回收站 / 插件中心 / 设置」，这是合法状态，不是空白。

### 3.2 窗口

| 窗口 | 布局 | 标题栏 | 入口 | 关闭 | 零插件下 |
|---|---|---|---|---|---|
| 主窗口 | 图标栏 + 侧栏 + 主区 + 状态栏 | 自绘常驻（可配自动隐藏） | — | 退出 | ✅ |
| 笔记独立窗口 | 编辑器 + **窗口内快速切换按钮**（左上下拉） | 自绘，标题居中 | 标签右键 / 拖出 / 菜单「在新窗口打开」 | 交回主窗口 | ✅ |
| 插件窗 / 整窗接管 | `PanelMount` 或插件自绘 | 同套标题栏 / 热区保留 | 面板右键 / 拖出 / 插件命令 | 关闭即销毁 / 「释放接管」 | ❌ 无插件即无入口 |

- 笔记窗口**不回复侧栏**（用户 2026-10-20 已定），只补「快速切换」：左上角按钮 → `QuickSwitcher`（`Ctrl+O` 同一组件）。所有窗口标题栏统一用 `<TitleBar>` 变体（`variant="note" | "plugin"`），不再各写一套。

### 3.3 浮层（保留，收敛）

| 浮层 | 用途 | 来源 | 变化 |
|---|---|---|---|
| 命令面板 / 快速切换 | 全部命令 / 找笔记 | 内核 + 插件命令 | 保留（兜底，不是导航）；零插件时只剩内核命令；笔记窗口内也可用 |
| 设置 | 偏好 | 内核 | 桌面 880×600 modal（两栏）；手机全屏页 |
| 搜索 | 找内容 | 内核 | **改为侧栏视图**（桌面）/ 全屏页（手机） |
| 全局替换 | 跨笔记替换 | 内核 | 保留浮层（破坏性操作要预览） |
| 反链 / 历史 / 标签 peek | 当前文档 / 标签 | 插件 | 从状态栏移到**文档工具条**；对应插件启用才出现 |
| 环形快捷入口 | 手机长按 ＋ | 内核 | 四项改为**搜索 / 插件 / 设置 / 最近**（全内核）；标签插件启用时可替换「最近」 |

## 4 入口矩阵（目标态，单一主入口）

| 功能 | 来源 | 主入口（可见） | 加速入口 | 零插件下 |
|---|---|---|---|---|
| 新建笔记 | 内核 | 侧栏头部 `＋` / 手机悬浮 `＋` | `Ctrl+N` | ✅ |
| 打开 / 切换笔记 | 内核 | 侧栏文件树 | `Ctrl+O` / 手机首页 | ✅ |
| 搜索 | 内核 | 图标栏 🔍 / 侧栏搜索框 / 手机底部 🔍 | `Ctrl+Shift+F` | ✅ |
| 时间流 | 内核 | 图标栏 🕒（侧栏视图） | 菜单 / 文件树右键 | ✅ |
| 智能分区（今天 / 最近 / 未打标签） | 内核 | 文件树视图顶部 | — | ✅ |
| 插件中心（装 / 卸 / 升 / 市场） | 内核壳 | 图标栏 🧩 / 手机底部 🧩 | 设置 → 插件（只留链接） | ✅（空态） |
| 设置 | 内核 | 图标栏 ⚙ / 手机「更多」 | `Ctrl+,` | ✅ |
| 回收站 | 内核 | 侧栏底部 / 手机「更多」 | 命令面板 | ✅ |
| 切换库 | 内核 | 侧栏底部库名 | 菜单「打开笔记库…」 | ✅ |
| 标签（浏览 / 筛选） | 插件 `tag-panel` | 插件固定区 / 命令面板 | 首页顶部 chip（启用后） | ❌ 整块不出现 |
| 反链 / 历史 | 插件 `backlinks` / `history` | 文档工具条（当前笔记） | 命令面板 | ❌ 工具条只剩内核动作 |
| 同步 | 插件 `sync-*` | 状态栏同步 chip | 插件中心 / 命令面板 | ❌ chip 不出现 |
| 导入 / 导出 | 插件 `import-export` | 菜单 | 插件中心 | ❌ 菜单项不出现 |
| 文档阅读器 | 插件 `doc-reader` | 打开 PDF/EPUB 即开 | 插件中心 | ❌ |
| 独立窗口 | 内核 | 标签右键 / 拖出 | 菜单「窗口」 | ✅ |
| 全局替换 | 内核 | 菜单 | `Ctrl+Shift+H` | ✅ |
| 命令面板 | 内核 | `Ctrl+P` | 菜单 | ✅（只剩内核命令） |

- 规则 1：**同一功能最多 1 个主入口 + 2 个加速入口**；多出来的入口必须删掉（例如「设置 → 插件」改为链接到插件中心）。
- 规则 2：`☰` 菜单只保留上表「加速入口」列里的项，**不再列插件面板**；「设置」不进菜单（与图标栏 ⚙ 重复，保留 `Ctrl+,` 作加速键）。
- 规则 3（零插件）：**来源 = 插件的行，在插件被禁用时整行入口消失**；容器（菜单 / 工具条 / 状态栏 / 底部导航）本身保留，不为它留空位。

## 7 与插件契约的关系

1. **不新增原语**：图标栏 / 底部导航 / 侧栏视图都是内核壳的 UI，不需要插件 API。
2. `location: sidebar`：当前被渲染到主区（`App.tsx:3671-3680`）。本方案给侧栏一个真实视图容器后，两种选择：
   - **A（推荐）**：`sidebar` 面板渲染到侧栏「插件」分组下（文件树下方），高度受限；**该分组在零插件 / 全禁用时不渲染**；
   - **B**：废弃 `sidebar`，统一按 `main` 处理，契约标 deprecated。
   - 需要用户拍板（§8-Q4）。
3. `location: statusbar`：保留，但约束为「一行文本/chip，不放大按钮」；反链/历史若继续用 statusbar，改为状态文字 + 点击打开浮层。**禁用即整块不渲染。**
4. `location: modal` / `editor-toolbar` / `editor-topbar`：不变。
5. 插件面板「每文档一签」（doc-reader）保持；工具页标签标题前加插件图标（16px），不改 `panel id`。
6. **零插件契约（新增约束）**：壳只渲染「当前已启用插件」注册的面板 / 命令 / 状态项；任何入口都不得缓存「曾经装过但已禁用」的插件。壳的固定项（图标栏 5 项 / 手机底部 4 项 / 侧栏 3 视图）**禁止**依赖插件能力。
7. **运行中禁用插件**：已打开的工具页标签要立即处理 —— 面板能释放就关闭标签，不能释放就显示「插件已禁用」+「重新启用」按钮；不允许留下白屏标签。预装失败（`ensureBuiltinPlugins` 的 `failed[]`）要走同一条空态路径，不弹死对话框。
