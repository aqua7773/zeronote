## 手机 / adb

- **装的是哪种包决定一切**：只有 `pnpm tauri android dev --config tauri.android-dev.json` 装出来的包才连 `192.168.1.3:1420`；`build` 出的 `app-*-debug.apk` 是**离线包**（内置 dist），点不动也连不上 dev。判据：`dumpsys package` 能看 versionName，但"连不连 dev"只能看点击有没有响应 / 页面是否热更新。
- **连通性别用 ping**：Windows 拦 ICMP 会误判成不通。用 `adb shell "toybox nc -w 3 192.168.1.3 1420 </dev/null && echo OK"`。
- **`adb reverse tcp:1420` 对 dev 包无效**：tauri CLI 把 devUrl 的 `localhost` 换成局域网 IP，手机走 WiFi 直连宿主机；reverse 只对 `localhost` 有效。
- **点小按钮用 swipe 不用 tap**：`input tap` 在 WebView 里点卡片 ⋯ 这类小目标常常不生效；`input swipe x y x y 700`（同坐标按住 700ms）可靠。
- **截图**：`adb shell screencap -p /sdcard/x.png` + `adb pull`；**CDP `shot` 抓不到 WebView 里的 canvas**。
- **设备分工**：测试机 `33b676f6`（Redmi 24069RA21C）只跑 `com.aqua.zeronote.debug`；正式机 `324652868237`（努比亚）只做 release 验收，不调试 / 不 push / 不改系统设置。
- **Android dev 构建**：`android-dev.cmd`（WMI 起，日志 `.self-logs/android-dev.log`）。三条硬前置：① 4 个 android target 已装 ② vite 必须让局域网可达（`host` 不能只听 localhost）③ 库不能放 PC 路径。

## Tauri / WebView 平台

- **CSP 开着时，local scheme 的 iframe 里内联脚本必被拦**：Tauri 编译会给 `script-src` 注入打包资源的 sha256，而 CSP 规范规定「源列表里有 hash/nonce 时 `'unsafe-inline'` 被忽略」⇒ `data:` / `blob:` / `srcdoc` 的 iframe（继承宿主 CSP）里内联脚本一律 blocked（logcat 原话：`'unsafe-inline' is ignored if either a hash or nonce value is present`）。**要给插件页面跑自带脚本，页面必须来自独立 origin（http(s):）**。
- **Tauri asset 协议在 Android 上不服务 `.html`**：`http://asset.localhost/…/page.html` → `net::ERR_INVALID_RESPONSE`（把 `assetProtocol.scope` 放宽到 `/storage/**` 也一样）；图片可以，HTML 不行。
- **插件注册进宿主表的资源必须由宿主兜底回收**：`command.register` / `view.registerPanel` / `registerWebView` 由 `ctx` 外层自动登记进 `subscriptions`；指望插件作者手写 `subscriptions.push(...)` 不现实（`examples/` 里 8 个示例都忘了，代价 = 重载必崩「命令 id 重复」，首次安装完全看不出来）。
- **StrictMode 已移除**（`src/main.tsx`）：插件加载是异步 + 副作用密集，双调用会与异步清理竞争 —— 别加回去。
- **改库内 `.zn/plugins/**` 不热更新**：vite 不监视库目录，要重启或点「重新扫描」。

## 验收方法论（桌面 / 真机）

- **`adb push <目录> <已存在的目标目录>` 会多套一层**：文件被推成 `<目标>/<源目录名>/…`，而插件只认一层。推单个文件到明确路径，或先删目标目录。
- **WebView2 的 CDP 端点只认 `node fetch`**：`Invoke-WebRequest` / PowerShell 的 HTTP 栈一律 404（不是权限、不是端口问题）。
- **`GetWindowRect` 含 DWM 边框（Win10/11 每边约 8px）**：按它截图会截到窗口外的画面（曾把截图越界当成布局 bug）。截图区域按 `rect` 向内缩 ~10px。
- **点击前先点一下空白处**：非活动窗口的第一次点击会被系统吃掉用于激活。
- **别跨轮沿用截图坐标**：tab 栏横向滚动位置会变，上一轮的坐标下一轮就失效；同一脚本里先扫像素段再点。
- **测试文本别用拼音歧义串**：中文输入法会把 `zntest` 合成「只能testx」。
- **验收要挑「只可能由被测功能产生」的信号**：验「文件名进索引」时用单字母 `u`（正文不含 u，只有文件名含），命中即铁证。
- **改 `tauri.conf.json` 的 `devUrl` 加 `?vault=` 可切测试库**（tauri CLI 自动重启 ~40 秒），**验完必须改回**。
