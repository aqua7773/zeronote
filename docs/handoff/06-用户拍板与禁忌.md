## 2 发版

- **不发布 universal APK**（4 ABI 121 MB）。默认 arm64 ≈33 MB；0.9.25 的 121 MB 是唯一例外
- 发版必须同时更新 `update/latest.json` + `update/android.json`，否则应用内收不到新版
- Gitee 单文件 ≤100 MB；GitHub 是主渠道，Gitee 是镜像
- 只过 G1（verify）不许提发版 —— 必须 G2（亲手验）+ G3（用户确认）

## 3 测试环境

- **安卓测试机（`33b676f6`）只跑已装的 dev 包**：不重新编译、不安装新包
- **不装 release 包**到测试机
- **release 机（努比亚 `324652868237`）只做验收**：不调试、不 push、**不改系统设置**（动画缩放等曾被改动，已恢复）
- 设备与包类型不确定 → 先问，不猜

## 4 安全与权限

- 能力自述 + 签名可见，**不留「跳过权限确认」的一键开关**
- `editor.render` 接管能力**不做**（用户已拍板）
- 安全类插件（`security` / `secrets` / `private-notes`）**从市场主动安装**，不预装
- 令牌 / 密码**不写进仓库**；凭据只记位置与用法（见 01 分册 §6）

## 5 工程习惯

- **不建无谓目录 / 新分类**：「一时说不清的先问，别建」
- **过程产物不扔根目录**（`_tmp-*` 已经堆了几百个，别再增加）
- **测试/验收产生的插件不留「功能」**：探针只放 `examples/` 或临时目录，用完即删
- **用户要求「记住」的事 → 写进 `docs/handoff/`**，不靠会话记忆
- **破坏性操作先确认**（删除 / 重启客户端 / 改系统设置）
