**手机 dev 插件怎么更新**（改 `examples/` 不会自动生效，插件是从手机本地全局目录读的）：

```powershell
# 全局插件目录在应用私有目录：/data/user/0/com.aqua.zeronote.debug/.zn/plugins/
adb push examples\<id>\index.js /data/local/tmp/<id>-index.js
adb shell run-as com.aqua.zeronote.debug cp /data/local/tmp/<id>-index.js .zn/plugins/<id>/index.js
# manifest 里的 sha256 必须改成新入口的哈希，否则拒载：
adb shell run-as com.aqua.zeronote.debug cat .zn/plugins/<id>/manifest.json > _tmp\phone-manifest.json
#   本地 node 改 sha256 后推回；改了文件后旧签名失效 = 硬拒载 ⇒ 把 signature.json 改名为 .bak（unsigned 照常加载）
adb shell run-as com.aqua.zeronote.debug mv .zn/plugins/<id>/signature.json .zn/plugins/<id>/signature.json.bak
# 然后 CDP 里 location.reload() 让插件重新扫描
```

**包类型速记**：debug 包 = 连 dev server 的最新源码；release 包 = 打包产物，**只有它能代表「用户手上那一版」**。
真机报 bug 时先确认「哪台机 + 什么包 + 什么版本」，三者缺一先问。

### 3.1 dev 与 release 同时开（2026-11-05）

**默认不能同时开**：桌面注册了 `tauri-plugin-single-instance`（`src-tauri/src/lib.rs:4553`），dev 与 release 的 identifier 都是 `com.aqua.zeronote`（`tauri.conf.json:5`）⇒ 抢同一把锁，第二个启动的进程只把命令行参数转发给已有实例就退出（「双击 .md」走这条）——**看起来像 release 打开了，其实前台是 dev**。

现在 dev 用叠加配置走独立身份：

- `src-tauri/tauri.dev.conf.json`：`{"identifier": "com.aqua.zeronote.dev"}`
- `dev.cmd:18`：`pnpm tauri dev --config src-tauri/tauri.dev.conf.json`（CLI 语义是**合并**，后给的键覆盖）

带来的隔离：单实例锁 / 数据目录 `%APPDATA%\com.aqua.zeronote.dev` / WebView2 profile（`%LOCALAPPDATA%\com.aqua.zeronote.dev`）/ 插件目录 / 插件 store（**含 sync 的配置与 `baseline.v1`**）全部与 release 分开。

- 插件已复制一份到 `%APPDATA%\com.aqua.zeronote.dev\.zn\plugins\`（含 `trusted-keys.json`）；以后 dev 装/改插件只影响这一份。
- **首次启动 localStorage 是空的** ⇒ 会问选笔记库，选 `_tmp-vault-rt12`（不要选用户真实库）。
- 为什么要隔离：插件 store 是**全局一份、不分库**（`plugin_store_*` 把 `appDataDir()` 当 vault 传），原来 dev 在测试库同步一轮就会写脏 release 真实库的 sync 基线 ⇒ 两端判成「双端修改」冲突。

## 6 本机凭据与账号（只记位置与用法，**永不记值**）

> 规矩：token / 密码**不写进任何仓库文件**。这里只记「在哪、怎么用、有什么限制」。

**本会话读用户级环境变量**（进程启动时快照，新写的 `$env:` 读不到）：

```powershell
$t = [Environment]::GetEnvironmentVariable('GITEE_TOKEN','User')
```

**Gitee API 四个要点**（2026-11-04 实测）：

1. 验证：`GET https://gitee.com/api/v5/user` + `Authorization: token $t` → 200
2. 列 Release：`GET /api/v5/repos/legendary-bird-lin/zeronote/releases?access_token=$t`
3. 传附件：`POST .../releases/{id}/attach_files?access_token=$t` —— **token 放 query**，放 multipart 表单会 401；传完等几秒才出现在列表
4. 单文件上限 **100 MB**（121 MB 的 universal 传不上，这也是必须发 arm64 的一个理由）

> 新建的 DSH 会话仍读不到用户级变量？确认是否在**写入之前**启动 —— 那就要走注册表读法；新开的独立终端可直接 `$env:GITEE_TOKEN`。
