# 插件能力对照 · 需求规格 §2.1–2.8

> 生成：2026-10-12（HEAD `0eb7887`）
> 核实方式：逐条对照 `src/kernel/contract.ts` 的 **10 个原语**、**21 种 UINode**，
> 以及 `examples/` 下 **11 个示例插件的真机实测结果**（每条标了实证来源）。
> 判定口径：**能做** = 现有内核能力足以实现，不需要再动内核。

## 速览

| 模块 | 判定 | 阻塞项 |
|---|---|---|
| **2.1 灵感流** | ✅ **全部能做** | — |
| **2.2 编辑器** | ⚠️ 除「`[[x]]` 内联点击」外都能做 | atomic 自带的 wikilink 语法优先级更高 |
| **2.3 文件夹与标签** | ✅ **全部能做** | 文件夹 UI 得插件自己画（内核侧栏是内核的） |
| **2.4 附件与大文件** | ⚠️ 一半卡 `net` | 同步/中转要 ⑧；视频首帧要 ⑩ |
| **2.5 同步** | ⚠️ 主体卡 `net` | WebDAV/实时同步要 ⑧；本地文件夹同步本就能做 |
| **2.6 密级与加密** | ✅ **主体能做** | 局域网传输要 ⑧ |
| **2.7 AI 自动标签** | ⚠️ 卡 `net` | ⑧ |
| **2.8 导出** | ✅ 基本能做 | 二进制落盘（zip/图片）缺一个小能力 |

**一句话**：**8 个模块里 4 个已完全可做、3 个卡在同一件事（`net`）、1 个卡在 `[[x]]` 的编辑器语法冲突**。

| 一条 = `笔记/年/月/日/HH-mm-ss.md` | ✅ | `fs.mkdir`（幂等）+ `fs.createNote` | **`examples/daily-note`**：toast「已建在当天目录：笔记/2026/10/12/02-23-46.md」 |

## 2.2 编辑器 ⚠️

| 要求 | 判定 | 靠什么 / 缺什么 |
|---|---|---|
| Effie 式即时渲染 | ✅ | **内核自带**（`@atomic-editor/editor`） |
| Markdown 全格式 | ✅ | 内核自带标题/列表/待办/表格/代码块/引用/图片；**公式、音视频**可在插件面板里用 `html` 节点渲染 |
| 字数统计 | ✅ | `doc.active().content` + `view:statusbar` |
| `[[文件名]]` 引用与跳转 | ⚠️ **着色能做，点击轮不到插件** | `editor.addMark` 能匹配并着色，但 **atomic 自己认得 `[[x]]`** 且用 `replace`/widget 类装饰（优先级高于 `mark`）⇒ 点击被它吃掉（HANDOFF 坑 ⑦） |
| 反向链接后置 | ✅ | `index.query` 扫全库 + 面板展示（**没有专用 API，但原语够**） |
| **「笔记」下只能在当天目录新建** | ✅ | **`command.bind('core.newNote', …)`** —— 内核四个入口全走这条命令 | **`examples/daily-note`**（实测） |
| 灵感流 ↔ 编辑器切换 | ✅ | `command` + `view`（`main` / `sidebar` 位置） |

## 2.3 文件夹与标签 ✅

| 要求 | 判定 | 靠什么 |
|---|---|---|
| 多层级文件夹 | ✅ | `fs.mkdir` / `fs.move` / `fs.delete`。⚠️ **UI 要插件自己画** —— 内核侧栏树是内核的，插件只能在自己的面板里画一棵 |
| 「笔记」结构固定、其他目录可增删改 | ✅ | `fs.move`（拒绝移进自己的子孙）+ `fs.delete` |
| 标签聚合查看 | ✅ | **`index.tags()`**（按笔记数降序） | **`tag-demo`**（实测） |
| 相似标签聚合 | ✅ | 算法自写（Levenshtein / 前缀聚类），原语够 |
| 搜索范围：正文、标题、标签 | ✅ | 正文=全文扫描；标题=`titleLower`（含文件名）；标签=**`index.query(q, { tag })`** | **`tag-demo`**（实测） |
| 第一版全文搜索 | ✅ | `index.query`（多关键词 AND + 中文子串） |

## 2.4 附件与大文件 ⚠️

| 要求 | 判定 | 靠什么 / 缺什么 |
|---|---|---|
| 阈值可配置 | ✅ | `store` |
| 小文件自动同步 / 大文件只存预览 | ⚠️ | **`net`**（⑧） |
| 预览：图片压缩 | ✅（未实测） | `OffscreenCanvas` → data URL → `image` 节点（**不需要 DOM**） |
| 预览：**视频首帧** | ❌ | 需要真实 `<video>` 元素 ⇒ 卡 **⑩ WebView**（`OffscreenCanvas` 解不了视频） |
| 预览：音频波形 | ✅（未实测） | Web Audio API（不需 DOM）→ SVG → `html` 节点 |
| 预览：PDF 首页 | ✅（未实测） | pdf.js（CDN）+ canvas → data URL |
| 预览：其他类型图标+文件名 | ✅ | `image` / `badge` / `text` |
| 大文件点击提示 | ✅ | `modal` 位置的面板 |
| 端→云→端中转 | ⚠️ | **`net`**（⑧） |
| 源设备离线时查其他设备 | ⚠️ **纯客户端做不到** | 需要**云侧协调**（谁在线、谁有本地副本）—— 这超出客户端插件范围 |
| 预览始终保留 | ⚠️ | **`net`**（⑧） |

## 2.5 同步 ⚠️

| 要求 | 判定 | 靠什么 / 缺什么 |
|---|---|---|
| 实时自动同步 | ⚠️ | `fs.watch` + `setInterval` 已有；**传输要 `net`**（⑧） |
| **WebDAV** | ⚠️ | **`net`**（⑧）—— 协议本身是纯 HTTP，一旦有 `net` 即可实现 |
| **本地文件夹同步** | ✅ **本来就能做** | 用户配 Syncthing / OneDrive 盯住库目录即可；插件只需保证文件都写在库内。⚠️ **`fs` 写不了库外是故意的**（`resolve()` 只收库内相对路径） |
| 冲突：以最新为准 | ✅ | `fs` + `store` 记录 mtime |
| 冲突：生成副本、不阻塞 | ✅ | `fs.createNote`（不覆盖）+ `host.notify` |
| 副本按平台分文件夹 | ✅ | `fs.mkdir` + `fs.move` |
| 同步状态页（进度/大文件/错误） | ✅ | **`progress` + `badge` + `table`** —— 这三个节点就是为它加的 |

## 2.6 密级与加密 ✅

| 要求 | 判定 | 靠什么 | 实证 |
|---|---|---|---|
| frontmatter 标密级 | ✅ | `fs.writeText`（改全文） |
| 公开：可明文 | ✅ | — |
| 秘密：传输加密 | ✅ | HTTPS 自带（需 `net`） |
| 机密：端到端加密 | ✅ | **`dep-crypto` 前置插件**（WebCrypto AES-GCM） | **加密自检通过**（真机） |
| 绝密：仅本地/局域网 | ⚠️ | 「仅本地」✅；**局域网传输要 `net`** |
| AI 标签按密级禁用 | ✅ | 插件自己判断（读 frontmatter） |
| 搜索索引按密级分 | ✅ | **`index.scoped('密级')`** | **`index-scope`**（默认 0 条 / 机密 1 条） |
| 密钥管理：主密码+设备密钥+恢复码 | ✅ | **`dep-crypto`**（PBKDF2 21万次 → 密钥在内存）+ `store` 存 salt/密文 | 同上 |

## 2.7 AI 自动标签 ⚠️

| 要求 | 判定 | 靠什么 / 缺什么 |
|---|---|---|
| 调大模型 API 打标签 | ⚠️ | **`net`**（⑧） |
| 普通全文搜索 | ✅ | `index.query` |
| 语义搜索（后置） | ⚠️ | embedding 也要 **`net`**（⑧） |
| 机密/绝密禁用大模型 | ✅ | 插件自判 + `index.scoped` 隔离 |

## 2.8 导出 ✅

| 要求 | 判定 | 靠什么 / 缺什么 |
|---|---|---|
| PDF | ✅ | jsPDF（CDN）→ `host.saveFile` |
| HTML | ✅ | marked（CDN）→ `saveFile` |
| Word | ✅ | docx（CDN）→ `saveFile` |
| 图片 | ⚠️ | html2canvas（CDN）产出的是**二进制** ⇒ 见下方"二进制落盘"缺口 |
| 纯文本 / Markdown | ✅ | `fs` 或 `saveFile` |
| 附件保留链接 | ✅ | 正文原样 |
| **需要时打包附件** | ⚠️ | fflate（CDN）能打 zip，但 **`saveFile` 目前只收字符串** ⇒ 需先转 base64 且要补二进制通道 |
| ⚠️ **批量导出** | ⚠️ | **Android 没有目录选择器**（Tauri 返回 `FolderPickerNotImplemented`）⇒ 只能逐个 `saveFile` |

## 做不了的，只有四类

| 类别 | 具体 | 根因 |
|---|---|---|
| **要 `net`** | 2.4 同步 / 2.5 WebDAV / 2.7 AI 标签 | 缺授权通道（⑧，等你裁决） |
| **要真 DOM** | 2.4 视频首帧 | `registerWebView` 现在抛错（⑩，等你裁决） |
| **要云侧协调** | 2.4「源设备离线时查其他设备」 | 纯客户端无从得知"谁在线、谁有副本" |
| **要二进制落盘** | 2.8 图片/zip 导出 | `saveFile` 只收字符串 ⚠️ **这是唯一一个不涉安全、可以马上补的小缺口** |

## 如果要继续（按性价比）

| 优先级 | 做什么 | 解锁 | 是否需授权 |
|---|---|---|---|
| **1** | `saveFile` 支持二进制（`Uint8Array` / base64） | 2.8 的图片与 zip 导出 | **不需要** |
| **2** | ⑧ `net` 授权通道 | 2.4 / 2.5 / 2.7 大半 | **需要**（安全模型） |
| **3** | ⑩ WebView 逃生口 | 2.4 视频首帧、画布类插件 | **需要**（CSP） |
| **4** | 与 atomic 协商 `[[x]]` 接管 | 2.2 的 `[[引用]]` 点击跳转 | 不需要（但要改第三方集成方式） |
