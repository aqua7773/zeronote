## 为什么单独放

AI 每次换会话都会重新提议同一批方案（沙箱、同步、Tantivy、共享 extension host）。这里只记两件事：**已经决定过什么**、**什么条件下才重议**。论证过程留在 `docs/*-调研-*.md`，最高原则留在 `docs/架构原则-2026-10-13.md`。

| 状态 | 含义 |

| `superseded` | 被新决策取代，文件保留，索引标注指向新 id |
