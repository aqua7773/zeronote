## 为什么单独放

AI 每次换会话都会重新提议同一批方案（沙箱、Tantivy、共享 extension host、插件市场）。这里只记两件事：**已经决定过什么**、**什么条件下才重议**。论证过程留在 `docs/*-调研-*.md`，最高原则留在 `docs/架构原则-2026-10-13.md`。

> 同步是个特例：D-002 曾定「不做」，2026-10-24 用户拍板重议，2026-10-25 以 **D-009** 取代（仍不做账号 / 服务端）。
