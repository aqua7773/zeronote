> 状态：**active** ｜最后核对：2026-10-20 ｜权威范围：库布局 / 笔记格式 / `.zn` / localStorage / 写入语义 / 迁移

## 1 库（vault）

| 场景 | 位置 | 代码锚点 |
|---|---|---|
| 桌面 | 用户任选文件夹 | `dialog.open({ directory: true })` |
| 手机默认库 | `/storage/emulated/0/Documents/ZeroNote`（公共存储；需「所有文件访问」） | `src/App.tsx:12` `ANDROID_VAULT` |
| 手机其它库 | `<库根>/.vaults/<名字>/` | `src/lib/vaults.ts` · `lib.rs` `VAULTS_DIR` |
| `.zn` 落点 | 库根；**子库提升到容器根**（`private_root`） | `lib.rs` `private_root` |

规则：

- `.vaults` 以 `.` 开头，文件树跳过所有 `.` 目录 ⇒ 容器里的库不会串进默认库。
- 同一库的判重口径：斜杠方向与大小写不敏感（`vaultKey`）。
- 切换库不换插件代码（插件全局唯一），但**换 store**（见 §3）。

## 2 笔记文件

| 类型 | 扩展名 | 打开方式 |
|---|---|---|
| 笔记 | `.md` / `.markdown` | 编辑器（可写） |
| 只读文档 | `pdf` / `epub` / `mobi` / `azw3` / `azw` / `fb2` / `cbz` / `txt` | 阅读器（只读） |

- 编码：UTF-8；**没有私有格式、没有数据库**。
- frontmatter：只解析文件开头 `---` 块里的**顶层 `key: value` 标量**（`lib.rs parse_frontmatter`）。
- 标题回退顺序：`frontmatter.title` → 正文第一个 `# ` → 文件名。
- 库内相对路径即身份（`NoteMeta.path` 为相对路径；绝对路径不允许越过库根）。

## 3 `.zn/`（库内私有目录，不进文件树、不入 git）

| 路径 | 内容 | 写入者 | 生命周期 |
|---|---|---|---|
| `.zn/ids.json` | `{ 库内相对路径: id }` | 内核（`lib.rs`） | rename 时 ID 跟随；外部移动会丢 |
| `.zn/trash/<stamp>/<原相对路径>` | 回收站条目，附 `.origin`（原路径） | `delete_note` | `restore_trash` 回原处；`purge_trash` 不可逆 |
| `.zn/plugins/<id>/store.json` | 插件 KV（按库隔离） | `plugin_store_write` | 换库 = 换一份；与全局插件代码分居 |
| `.zn/watchdog.log` | 卡死留痕（前端无响应） | Rust 看门狗 | 只追加 |

回收站旧格式（扁平条目）由 `list_trash` 兼容读取；新格式是「一层目录 + `.origin`」。

## 6 写入语义

- **所有写入原子**：同目录临时文件 → fsync → `rename`；`rename` 失败走 `.zn-bak` 三步（旧文件→bak，新文件→原位，成功后删 bak）。Windows 的 rename 本身可覆盖，旧注释说「不覆盖」是错的（`lib.rs atomic_write`）。
- **删除**：逻辑删除进 `.zn/trash/`；物理删除是第二步，需二次确认。
- **rename**：ID 跟随 + 全库重写 `[[旧名]]` / `[[旧名|显示]]` / `[[旧标题]]` / `](旧路径)`。
- **保存**：停笔 800ms 自动保存 + `Ctrl+S` + 关窗前落盘；写盘前与磁盘做行级三方合并（`src/lib/merge3.ts`），冲突时 mine 赢并提示。
- **外部改动**（rev173.59 已修）：桌面由 Rust `notify` watcher 推 `zn://fs-change`（只报库内 `.md`、120ms 合并、1.5 秒自写抑制）；移动端（FUSE 漏报）前端 3 秒轮询兜底。`src/kernel/fs.ts` 只在 `watch_vault` 成功后才 `stopPoll()`，watcher 起不来时轮询保留。

## 7 索引与缓存（不落盘）

| 数据 | 位置 | 生命周期 |
|---|---|---|
| 全文索引 | 内存子串索引（`src/kernel/index-api.ts`） | 进程内；重启重建；增量 upsert/remove（rev173.40） |
| 编辑器撤销/光标/滚动 | 内存，按路径缓存 | 切标签保留；关标签释放 |
| 回收站/文档预览 | 按需读取 | 不缓存到磁盘 |

## 8 备份与恢复

| 层 | 手段 | 说明 |
|---|---|---|
| 内核代码 | `_kernel-snapshots/` + `scripts/kernel-snapshot.mjs` / `kernel-restore.mjs` | 仓库侧快照，gitignored；`修复内核.cmd` 一键恢复 |
| 用户笔记 | 用户自己的文件夹备份（网盘/移动硬盘） | 无云同步、无账号（[`D-002`](decisions/D-002-不做云同步.md)） |
| 删除误操作 | `.zn/trash/` 回收站 | 恢复回原处或物理清空 |
| 插件 | 全局插件目录即备份单位 | 装卸 = 复制/删除一个文件夹 |
