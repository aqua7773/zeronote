# 项目结构

> 状态：**active** ｜最后核对：2026-11-04 ｜权威范围：目录职责 + 关键入口（**「我该改哪个文件」先看这里**）
> 架构视角（拓扑 / 主流程 / 数据流）在 [`docs/系统总览.md`](../系统总览.md) §9 模块地图，本文只做导航。

## 1 顶层目录

| 目录 | 职责 | 什么时候进去 |
|---|---|---|
| `src/` | 前端（React 19 + TS） | 改 UI / 内核 JS 侧 |
| `src-tauri/` | Rust 侧（Tauri 2） | 改文件 IO / 命令 / 平台能力 |
| `examples/` | **40 个示例插件**（真功能都在这） | 改插件、加插件 |
| `market/` | 插件市场（`index.json` + `packs/*.znp`） | 发插件、改签名 |
| `scripts/` | 构建 / 生成 / 门禁脚本 | 发版、检查 |
| `tests/` | vitest 单测（1918 条） | 改逻辑必补 |
| `tools/` | 调试工具（`cdp.mjs` / `cdp-profile.mjs`） | 桌面 CDP 实测 |
| `update/` | 应用更新清单（`latest.json` / `android.json`） | **每次发版必改** |
| `docs/` | 文档（权威矩阵在 `docs/README.md`） | 查规矩 / 写文档 |
| `docs/handoff/` | **本套接手分册** | 接手第一站 |
| `patches/` | 依赖补丁 | 少动 |
| `public/` / `dist/` | 静态资源 / 构建产物 | 不用手改 |
| `_shots/` | 截图证据 | 验收留证 |
| `_research/` | 外部调研（historical） | 只读 |

⚠️ **根目录很脏**：几百个 `_tmp-*`、`_verify-*.log`、`verify-out*.log`、测试笔记 `.md` 直接躺在根目录。
新产物**不要再丢根目录** —— 临时进 `_tmp/`，日志进 `_build/` 或临时目录。

## 2 `src/` 内部

| 目录 | 文件数 | 职责 |
|---|---|---|
| `src/kernel/` | 34 | **内核 JS 侧**：契约、命令、事件、文件 IO、编辑器接线 |
| `src/components/` | 44 | UI 组件（侧栏 / 文件树 / 编辑器 / 移动端抽屉…） |
| `src/hooks/` | 8 | `useDocIO` / `useDocSession` / `usePluginHost` / `useWindowGuard` … |
| `src/lib/` | 43 | 纯函数工具（路径 / 版本比较 / 长按反馈 / 分享…） |

**内核关键文件**（改行为前必看）：

| 文件 | 内容 |
|---|---|
| `kernel/contract.ts` | **契约真相**（PluginContext / 原语 / manifest 类型） |
| `kernel/kernel.ts` | 内核装配入口 |
| `kernel/fs.ts` | 文件树 + 轮询兜底（`list_notes` / `list_notes_light`） |
| `kernel/doc-*.ts` | 笔记读写 / codec 注册 |
| `kernel/command.ts` · `event.ts` | 命令总线 / 事件总线 |
| `kernel/capability.ts` | 核心能力接管（`search.query` / `storage.*`） |
| `kernel/market.ts` · `app-update.ts` | 插件市场 / 应用更新 |
| `kernel/editor-*.ts` | CodeMirror 扩展（语法 / 标记 / 缩进 / frontmatter） |

## 3 前端入口链

```
index.html（内联启动兜底）
└─ src/main.tsx（createRoot，置 __znBooted）
   └─ src/App.tsx（巨型组件：布局 / 路由 / 浮层 / 移动端分支）
      ├─ src/hooks/*（状态与 IO）
      ├─ src/components/*（UI）
      └─ src/kernel/*（能力）
```

`App.tsx` 6000+ 行，改之前先看 `docs/开发约定.md` §2（hook 约定）；新逻辑优先落 `src/hooks/` 或 `src/lib/`。

## 4 `src-tauri/` 内部

| 路径 | 内容 |
|---|---|
| `src/lib.rs` | 命令注册总入口 |
| `src/*.rs` | 各领域命令（fs / notes / assets / media_server / updates / widgets…） |
| `plugins/` | 原生插件（`statusbar` / `crashlog` / `biometric` / `apk-install`） |
| `gen/android/` | Android 工程（Kotlin 原生 + Gradle + widget） |
| `capabilities/` | Tauri 权限声明 |
| `Cargo.toml` | 依赖 + **无 `[profile.release]` strip**（APK 大的一因，见 02 分册） |

## 5 插件（`examples/`）

每个插件 = 一个目录：`plugin.json`（manifest）+ `index.js`（入口）+ 可选 `styles.css`。
写新插件先抄最接近的那个；契约见 [`docs/内核契约-v0.2.md`](../内核契约-v0.2.md) §2–§3。
产物打包成 `.znp` 进 `market/packs/`（命令见 `market/README.md`）。

## 6 测试与脚本

| 位置 | 内容 |
|---|---|
| `tests/*.test.ts(x)` | vitest（happy-dom）；`pnpm exec vitest run tests/xxx.test.ts` 跑单个 |
| `src-tauri/src/**/tests` 或 `#[cfg(test)]` | Rust 单测（`cargo test --lib`） |
| `scripts/verify.ps1` | 六步门禁 |
| `scripts/check-docs.mjs` · `check-links.mjs` | 文档门 |
| `scripts/build-release.mjs` · `gen-update-manifest.mjs` | 发版（见 02 分册） |
