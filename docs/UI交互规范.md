### 1.2 图标栏（48px，`AppRail.tsx`）

| # | 图标 | 名称 | 点击 | 再点 | 零插件 |
|---|---|---|---|---|---|
| 1 | 📄 | 笔记 | 侧栏切「文件树」 | 收起侧栏 | ✅ |
| 2 | 🔍 | 搜索 | 侧栏切「搜索」视图并聚焦 | 收起侧栏 | ✅ |
| 3 | 🕒 | 时间流 | 侧栏切「时间流」 | 收起侧栏 | ✅ |
| 4 | 🧩 | 插件 | 主区打开**插件中心**页 | 回到之前的文档 | ✅（空态 + 安装 + 市场） |
| 5 | ⚙ | 设置 | 打开设置 | 关闭 | ✅ |

- **插件固定区**（分隔线以下）：用户在插件中心每行点 📌 固定，**最多 3 个**；只存插件 id，插件禁用/卸载 ⇒ 该项**自然消失**，重新启用自动回来；满 3 个后未固定的按钮置灰 + tooltip 说明（`lib/rail-pins.ts`）。空 ⇒ **整块不渲染**（不留灰位、不画分隔线）。
- 点击 pin = 打开该插件**第一个可打开的页面面板**并进标签条；一个面板都没有时如实提示，不留死按钮。
- 选中态 = 图标 + 2px 左侧竖条 + 深色底 + `aria-current="page"`；每个按钮 tooltip 带快捷键。
- **不随侧栏收起**（Obsidian Ribbon 规则）。图标 20px（B7 两档之一）。

### 1.3 侧栏（260px，`AppSidebar.tsx`）

- **视图容器**：文件树 / 搜索 / 时间流三选一，切换不改宽度；顶部固定搜索框（输入即切搜索视图）+ 收起按钮 `«`。
- 宽度可拖 **220–420**（默认 260，记忆 `zeronote.sidebar.w`）；分隔线可 Tab 聚焦 + `←/→/Home/End` 调宽（WCAG 2.5.7）。
- **收起 / 展开**（rev173.267）：宽度滑 **220ms**（`--zn-dur-panel` / emphasized）；**拖动分隔线时 0**（`body.is-resizing`），否则手感会「拖不动」。收起 = 宽度到 0 + `inert`（不可 Tab / 不可点），**不卸载** —— 文件树的滚动位置与展开状态保留；分隔线只在展开时渲染。
- **智能分区**（只在文件树视图，桌面专用，`SmartSections.tsx`）：搜索框下方一行 chip —— **今天 / 最近 7 天 / 未打标签**；点中 ⇒ 文件树区域换成扁平列表（按 mtime 倒序），`‹` 返回。分区是**视图**不是目录，不往文件树里插虚拟分组。
  - 「今天」= 本地 0 点之后；「最近 7 天」= 含今天共 7 个自然日；「未打标签」走内核 `index.query('', { untagged: true })`（标签来源含正文 `#标签`）。
  - 列表标题剥掉 Markdown 标记（`#` / `![](…)` / `[[路径|别名]]`）。
- **侧栏插件分组**（`location: 'sidebar'`）：渲染在文件树下方、最多占侧栏 45%、内部滚动；零插件 / 全禁用整块不渲染；手机没有常驻侧栏 ⇒ 回退主区。
- 底部：回收站（按钮）+ 库名（点击弹切换库）。

### 1.5 标题栏与专注模式

- 32px 自绘，菜单与窗口控制同一行；**默认常驻**。
- **专注模式**（设置 → 通用，默认关，`zeronote.focusMode`）：开启后标题栏自动隐藏 —— 鼠标进顶部 20px 热区 / 标题栏本身 / 键盘焦点进入标题栏时滑回，`clientY > 64` 收起；时长 200ms（`--zn-dur-titlebar`）。
- 热区（`.zn-titlebar-hotzone`）同时兼任拖动区 —— 标题栏藏起来时窗口仍可拖动。

## 2 手机（< 641px）

- **单窗口**，整窗接管；起始页 = 卡片流（`MobileNoteCards`）。
- **底部四项**（`MobileTabBar.tsx`）：**首页 / 搜索 / 插件 / 更多**，固定 id 与顺序，`aria-current="page"` + 顶部短竖线；贴底吃 `env(safe-area-inset-bottom)`；**编辑态 / 工具页 / 回收站时隐藏**（编辑态由键盘上方工具栏接管）。
- **「更多」是全屏页**（`MobileMorePage.tsx`）：笔记组（回收站 / 切换笔记库 / 插件中心）+ 插件组（启用的插件入口，禁用即整组消失）+ 其他（设置 / 关于）。
- **搜索是全屏页**（复用侧栏搜索面板 + `‹ 返回`），桌面仍是侧栏视图。
- **编辑态顶栏**：`‹ 返回 | 笔记名 | ⋯`；`‹` = 关笔记回列表，`⋯` = 主菜单，长按 ☰ 保留为加速手势。
- **抽屉**：左→右滑打开（**输入状态下不打开**）、右→左滑关闭；阈值 `|dx| ≥ 60` 且明显大于纵向（`lib/swipe.ts`）；抽屉打开时隐藏系统状态栏。
- **返回键层级**：浮层 → 侧栏抽屉 → 当前笔记 → 非首页 tab 回首页 → 允许退出。一次只吃一层。
- 手机**不渲染**状态栏（底部让给四项，保存状态在顶栏）与智能分区（抽屉空间不够）。

## 3 浮层与出口层级

优先级从高到低（`App.tsx` 的 `backRef` 与 Escape effect）：

1. 自持浮层：☰ 菜单 / 库菜单 / 右键菜单 / 文件树多选 / 卡片菜单
2. 设置
3. 搜索
4. 快速切换（`QuickSwitcher`）
5. 侧栏抽屉
6. 当前笔记（`Ctrl+W` 语义：关当前标签）
7. 都没有 ⇒ Android 返回键允许退出

规则：

- **Escape 从内到外**，一次只关一层；各浮层自己先处理，App 只兜底。
- 点遮罩关闭；命令面板 560px 宽、距顶 12vh（`.zn-palette`）。
- 查找面板是悬挂窗（fixed），不改变正文布局。
- **Toast 与撤销条 / 草稿恢复条共用底部位置**：三者互斥（`undoDelete ? … : draft ? … : toast ? …`）。要表达「一直可见的状态」时**别依赖 toast** —— 它会被后一次渲染或上述两条挡住（rev173.264 实测）。

## 5 键位与无障碍

- 命令键位见 [`键位表.md`](键位表.md)（自动生成）。**不进命令表**的按键：`Ctrl+Tab`（标签切换，需捕获阶段）、`Esc`（关最上层）、`Ctrl+V`（剪贴板图片）、`Ctrl+F`（编辑器查找）、Android 返回键。
- **焦点圈**：`@layer base` 统一 `:focus-visible { outline: 2px solid var(--zn-fg) }`；贴边容器（图标栏）用 `outline-offset: -2px` 防裁切。鼠标点击不出圈。
- **目标尺寸**：可点元素 ≥ **24×24**（WCAG 2.5.8）—— 工具条按钮 24 高、状态栏 chip ≥24、`＋`/`»` 24×24、智能分区 chip 24 高。
- **拖拽有替代**：侧栏分隔线可 Tab + 方向键（2.5.7）。
- **reduce-motion 全局降级**：`prefers-reduced-motion: reduce` 下所有 `animation` / `transition` 压到 1ms `!important`（覆盖内联样式），页面钻入改直接切换。

### 6.1 页面转场（rev173.266）

四类语义，实现方式 = **React `key` 重挂载 + keyframes**（不引动画库、不用 JS 计时）：

| 语义 | 用在哪 | 运动 | 时长 |
|---|---|---|---|
| **同级切换** | 主区换系统页（插件中心 / 回收站）、面板 | 淡入 + 2px 上移 | 160ms（`--zn-dur-base`） |
| **钻入 / 返回** | 手机「列表 ↔ 编辑器」 | 进入从右 24px、返回从左 12px | 260ms（`--zn-dur-drill`，仅 ≤640px） |
| **浮层** | 设置 / 命令面板 / 快速切换 | 遮罩淡入 + 面板 `scale(.98)→1` | 遮罩 120ms · 面板 140ms（`--zn-dur-overlay`） |
| **高频（不做）** | 标签切换 | — | 0（同页换内容，不是页面转场） |

- 换页 key 只按**层级**变：`list` / `editor` / 系统页 / 面板 id —— **同层级换笔记不重挂载**，否则每点一篇都滑一次，比没动画更吵。
- reduce-motion 下全部被全局 `*` 规则压到 1ms（实测 `0.001s`）。

## 7 主题与视觉

- 主题三态 `light` / `dark` / `system`，偏好存 `zeronote.theme`；只写解析后的 `data-theme`，CSS 只有一条 `:root[data-theme='dark']` 分支（`lib/theme.ts`）。
- 首屏防闪：`index.html` 内联脚本在 React 挂载前设好 `data-theme`。
- 滚动条自绘（6px、无轨道、静止淡出），暗色单独配色。
- 安全区：`.zn-app` / `.zn-plugin-window` / `.zn-shell-host > .zn-shell-mount` 三处各吃 `env(safe-area-inset-*)`。
