# 术语与编号

> 状态：**active** ｜最后核对：2026-11-04 ｜权威范围：文档与对话里高频出现、接手时看不懂的缩写与编号

## 1 编号体系

| 编号 | 含义 | 怎么用 |
|---|---|---|
| `rev173.N` | **改动序号**，一个可交付单元 +1 | 提交信息 / `HANDOFF.md` 段标题 / 文档引用 |
| `rev173.365` | 第 365 个改动单元（当前） | 每完成一批改动 +1，同时写 HANDOFF 一段 |
| `0.9.x` | **发布版本**（用户可见） | tag `v0.9.x`、安装包文件名、`update/*.json` |
| `D-0xx` | **决策记录**编号 | `docs/decisions/D-0xx-*.md`；被推翻的标 superseded |
| `rev173.3xx` 范围 | 同一发布周期的改动 | 文档里用「rev173.232–245」表示一期功能 |

> 版本与 rev 不是一一对应：一个 `0.9.x` 通常包含十几个 rev。

## 2 内核术语

| 词 | 含义 |
|---|---|
| **空内核** | 内核只做 .md 读写 / 编辑 / 本地存储 / 插件宿主，其余全是插件 |
| **原语（primitive）** | 内核暴露给插件的 12 个基本能力（doc / fs / editor / ui / command / event …） |
| **UINode** | 插件声明式 UI 的 21 种节点类型 |
| **挂载位** | 插件可占的 6 个位置（sidebar / main / statusbar / modal / editor-toolbar / editor-topbar） |
| **capability** | 可被插件接管的核心能力（`search.query` / `storage.*`），有优先级与冲突选择 |
| **PluginContext（ctx）** | 插件拿到的上下文对象，成员见 `src/kernel/contract.ts` |
| **manifest** | `plugin.json`：id / 版本 / 能力自述 / 面板 / 命令声明 |
| **codec** | 文档编解码钩子（`doc.registerCodec`），私密笔记用它实现加密 |

## 3 文件与目录

| 名字 | 是什么 |
|---|---|
| `.zn/` | 应用数据目录（笔记库内）：插件 store、私密、回收站、审计、同步状态 |
| `.zn/plugins/<id>/` | **全局插件目录**（跨库共用） |
| `.znp` | 插件安装包（zip + `plugin.json` + 签名） |
| `market/index.json` | 插件市场索引（16 条） |
| `market/packs/*.znp` | 插件包（带签名） |
| `update/latest.json` / `android.json` | 应用更新清单（**发版必改**） |
| `.zn-assets/manifest.json` | 附件引用台账（sha256 身份） |
